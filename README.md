# Corgi Shooter: Ducks like Zombies

Play in the browser: https://luisgerardolms.github.io/corgi-shooter-web/

Top-down arcade shooter. Keyboard and Xbox controller. No touch controls.
Esc does not pause. The browser uses Esc to leave fullscreen.

This folder is the Godot 4.7.2 web export. The game source stays in a private repository.
The arcade font is Press Start 2P (SIL Open Font License).
